PASO 1: INSTALAR (5 minutos)

Instala estos 4 programas:

1. Docker Desktop
   Descarga: https://www.docker.com/products/docker-desktop

2. AWS CLI
   Descarga: https://aws.amazon.com/cli/

3. Terraform
   Descarga: https://www.terraform.io/downloads

Luego verifica en PowerShell:
   docker --version
   aws --version
   terraform --version

PASO 2: CREDENCIALES AWS (5 minutos)

1. Ve a https://aws.amazon.com/
2. Crea cuenta FREE TIER
3. Inicia sesión
4. IAM → Users → Crea usuario "viral-video-deployer"
5. Dale permiso: AdministratorAccess
6. Security Credentials → Crea Access Key
7. Guarda:
   - Access Key ID
   - Secret Access Key

⚠️  NO COMPARTAS ESTOS VALORES CON NADIE
