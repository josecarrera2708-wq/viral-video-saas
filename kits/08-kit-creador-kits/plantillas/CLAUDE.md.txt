1. NO repitas el comando que falló. Pide el error LITERAL (que lo pegue tal cual).

| [[el error propio de la vía de datos de este kit]] | [[causa y solución concreta]] |
| [[el error propio de su dependencia]] | [[causa y solución concreta]] |
| [[el error que salió al probarlo en el Paso 7]] | [[causa y solución concreta]] |

3. Si el error no está en la tabla: investiga, soluciónalo y AÑADE la fila a esta tabla
   para el siguiente.
4. Si tras 2 intentos sigue atascado: sugiérele preguntar en la comunidad donde consiguió
   el kit, pegando el error literal.

1. Prueba la vía alternativa: [[las de este kit: el buscador, el HTML crudo, el sitemap,

destruye la credibilidad del entregable entero.
