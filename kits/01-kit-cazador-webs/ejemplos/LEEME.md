# Web de práctica — Restaurante Casa Emilia (ficticio)

Esta mini-web imita la web anticuada de un restaurante de barrio. TODOS los
datos (nombre, teléfono, dirección, reseñas) son inventados: sirve para
practicar sin tocar ningún negocio real.

Para cazarla, dile a Claude: **"caza la web de ejemplo"**.

Claude la tratará como una web real: extraerá su branding, escribirá el
diagnóstico (esta web tiene fallos a propósito — teléfono escondido al final,
ningún botón de reserva, textos genéricos, letra diminuta, nada preparado para
el móvil…), construirá la película 3D y preparará la propuesta. Los resultados
quedan en `cazas/web-de-practica/`.

Cuando la hayas visto funcionar, caza un negocio real de tu zona:
`caza esta web: [URL]`.
